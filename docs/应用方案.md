# HORIZON 应用方案

> 看见未来，然后走向它。（SeetheFuture, Walking with You to the Future.）

HORIZON（Horizon 地平线人工智能）是一个基于百度秒哒（MiaoDa）平台开发、以 AI 为核心能力的**大学生未来规划与成长系统**。通过职业规划、成长树可视化、简历智能分析和成长伙伴陪伴，帮助大学生将长期目标转化为每日可执行的行动。

---

## 一、项目定位

### 1.1 项目背景

大学生在面临考研、就业、职业选择时，往往会遇到三个问题：

1. 不知道未来应该往哪个方向发展；
2. 知道目标，却不知道每一步应该做什么；
3. 制定了计划，却很难长期坚持执行。

目前市面上的规划工具大多停留在待办清单、固定模板或简单 AI 问答层面，缺少真正围绕用户目标**持续规划、动态调整和成长陪伴**的能力。

### 1.2 产品定位

HORIZON 不是普通聊天机器人，而是一套完整的未来成长系统，围绕四个核心环节建立闭环：

**规划 → 执行 → 反馈 → 优化**

用户不只是获得一个答案，而是获得一条能够持续推进的成长路线。

### 1.3 目标用户

- 在校大学生
- 应届毕业生
- 考研人群
- 职业探索青年
- 高校职业规划课程

## 二、核心功能 / 模块

平台包含八大核心功能模块，构成「规划、推演、陪伴与交付」的完整闭环：

| 模块 | 名称 | 功能说明 |
| --- | --- | --- |
| 01 | 核心功能（未来路线图 FUTURE_MAP） | 自动拆解四年成长路线、学期目标和每周任务，让长期目标不再悬在空中 |
| 02 | 人生岔路（路径模拟 PATH_SIM） | 点击不同职业方向生成不同成长路线，在做选择之前先看见未来 |
| 03 | 成长伙伴（陪伴 COMPANION） | 根据完成率动态调整计划，缓解成长焦虑，AI 伙伴带着完整上下文接住用户 |
| 04 | 简历中心（AI 简历 RESUME_AI） | AI 简历解析、岗位匹配与深度优化 |
| 05 | 成长档案（Growth Archive） | 每一步成长都被记录、被度量，用图形与进度条让「变好」可见，支持生成本周复盘周报 |
| 06 | 今日计划（Today's Plan） | 成长路线直接同步每日任务，执行闭环实时反馈与调整 |
| 07 | 求职追踪（Job Tracker） | 求职进度看板与 Offer 转化漏斗，每一次流转都被度量 |
| 08 | 成长数据舱（Data Dashboard） | 近 90 天成长数据仪表盘、未来概率预测、目标达成进度与风险项分析 |

### 2.1 AI 职业规划：个性化生成成长路线

用户既可以选择预设职业方向（AI 工程师、嵌入式工程师、产品经理、前端开发、考研等），也可以输入任意职业目标（如「我想成为机器人算法工程师」）。

AI 将自动生成：

- 职业介绍
- 核心能力要求
- 学习路线
- 推荐项目
- 实习方向
- 长期成长规划

真正做到**「一人一规划」**。

### 2.2 核心创新：Future Growth Tree 成长树

把未来变成一条可以看见的路，是 HORIZON 的核心创新功能。系统将长期目标拆解为多个成长阶段：

**当前状态 → 基础能力 → 项目实践 → 实习竞赛 → 专业方向 → 目标岗位**

每一个节点都可以点击查看详细内容（含建议推演周期、关键交付物、技能晶簇、NEXT_ACTION 指引），并一键加入个人成长计划，让抽象的未来变成具体的行动。

### 2.3 Horizon AI 成长伙伴：引导式成长对话

不是万能聊天机器人，而是**引导式成长对话**。选择你的困扰（焦虑、迷茫、方向选择、找实习、计划调整等），AI 会一步步陪你找到下一步并真正修改你的计划。

- 系统联动：AI 伙伴的操作会直接写入任务系统——创建 5 分钟启动任务、调整计划、推迟任务，实时同步到今日计划。
- 典型场景：用户说「今天没有完成任务」，AI 先分析原因，再生成下一步行动（拆分为 5 分钟启动任务、调整今日计划、延后任务、加入成长计划）。
- 真正形成：**AI 建议 → 用户行动 → 成长反馈**。

### 2.4 AI 简历中心：从上传到优化的完整流程

- 支持格式：PDF、DOCX、TXT（离线本地解析，文本层真实提取）。
- AI 自动完成：简历解析、教育经历识别、技能分析、项目经历分析、岗位匹配、修改建议。
- 深度优化：多维评分 + STAR 改写，输出「修改前 vs 修改后」对照与 ATS 关键词诊断，绝不伪造经历。
- 示例：目标岗位「AI 工程师」，系统自动分析已具备能力、缺失能力、能力差距，并生成 30 天提升计划。

## 三、产品架构与页面流程

### 3.1 AI 驱动架构

用户输入职业目标 → AI 分析目标需求 → 生成成长路线 → 成长树可视化 → 每日任务 → 成长反馈 → 持续优化，整个流程形成完整成长闭环。

### 3.2 用户操作流程

进入 HORIZON → 选择未来方向 → AI 生成成长路线 → 查看成长树 → 加入成长计划 → 上传简历 → AI 分析优化 → 每日执行 → 持续成长。

整个流程围绕用户成长进行设计，导航结构为：核心功能 / 人生岔路 / 成长伙伴 / 简历中心 / 成长档案 / 今日计划 / 求职追踪 / 成长数据舱。

### 3.3 核心界面要素

- **首页**：成长指数（如 86/100）、今日完成率、距离秋招天数与建议、情绪状态（疲惫·连续专注 7 天）、AI 建议（疲劳信号明显时优先休息并只保留 1 个任务）。
- **职业规划页**：职业简介、核心能力、学习路线（分阶段 + 加入计划）、实时行业信号与 AI 合成提示。
- **成长树页**：多阶段节点可点击查看详情、推演全新科技树、自定义推演方向。
- **今日计划页**：任务按阶段分组（如 O3_PROJECTS / 职业实践 / O2_FOUNDATION），标注建议时长（P145m / P60m），支持拆分为 5 个小步骤。
- **求职追踪页**：求职进度看板（准备中 / 已投递 / 笔试 / 面试中 / 已录用 / 已结束）与转化漏斗。

## 四、技术方案

- **开发平台**：基于百度秒哒（MiaoDa）平台开发，AI Web 应用。
- **前端形态**：Web 单页应用，样式、脚本、图表内联于单文件 `index.html`。
- **可视化**：ECharts 图表可视化（成长指数、完成率趋势、目标达成进度等）。
- **后端**：秒哒托管的 Supabase 数据服务，支持注册登录与数据存储。
- **AI 能力**：AI 在作品中是核心能力而非辅助功能，主要承担——理解用户目标、分析职业能力要求、动态生成成长路线、引导成长对话、解析简历内容、岗位匹配分析、生成每日行动建议、持续优化成长计划。

## 五、创新点与特色亮点

| 创新点 | 说明 |
| --- | --- |
| 成长树可视化规划 | 将长期目标转化为可视化成长路径 |
| 引导式 AI 成长伙伴 | 采用问题树交互，而不是固定聊天 |
| 规划执行闭环 | 成长路线直接同步每日任务 |
| 职业规划与简历联动 | 发现能力差距后自动生成提升计划 |

相比普通规划工具，HORIZON 更强调**长期成长陪伴**：AI 将多个独立功能连接成一个持续成长系统。

## 七、项目总结

看见未来，然后走向它。HORIZON 希望解决的不只是「未来做什么」，更重要的是帮助用户明确**下一步应该做什么**。

未来，我们希望 HORIZON 成为大学生成长过程中的 AI 智能伙伴，让规划真正落地，让成长真正发生。地平线代表未来的方向，每前进一步，都会看到新的可能。

> Life has no Ctrl+Z, but you can simulate ahead.
> 输入你的第一个目标，剩下的交给 Horizon。
